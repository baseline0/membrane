## Systematic Fetching Strategy

### Step 1: Check These Databases First (in order)
1. **Google Scholar** — Best starting point, links to PDF when available
2. **MDPI** (papers #5, #9) — Fully open access
3. **IEEE Access** (paper #7) — Fully open access
4. **ArXiv** — Pre-prints and open submissions
5. **ResearchGate** — Authors often upload their own papers
6. **Institutional repositories** — University links often have PDFs

### Step 2: For Each Paper
```bash
# 1. Google Scholar search
https://scholar.google.com/scholar?q=[TITLE]

# 2. If found, check for [PDF] link on right sidebar
# 3. If no PDF link, try:
#    - Check "Cited by" and "Related" articles
#    - Look for ResearchGate link
#    - Check author's university page
```

### Step 3: Fallback Options
- **Institutional access**: Use your university/organization login if available
- **Email author**: ResearchGate allows direct messaging to authors
- **Library services**: Many universities offer interlibrary loan
